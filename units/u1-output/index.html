🖨️ 輸出與變數

程式的第一步：讓電腦「說話」（輸出），以及用「變數」把資料記下來。我們用生科教室常見的數值——馬達轉速、感測器讀值、材料尺寸——來練。

🔄 型別轉換 int()

1. 用 print 輸出

print() 會把括號裡的東西顯示出來。文字（字串）要用引號包起來：

# 印出一段文字
print("馬達啟動")   # 螢幕顯示：馬達啟動

數字不用引號，直接放進去就好：print(120)。

2. 變數：把資料記下來

變數就像貼了標籤的盒子。= 是「把右邊的值存進左邊的變數」：

rpm = 120          # 把 120 存進變數 rpm
print(rpm)         # 顯示 120（注意：印變數不用引號）

變數可以參與運算，例如兩段木料長度相加：total = a + b。

3. f-string：把變數塞進文字裡

想輸出「目前溫度：25°C」這種混合文字和數值的句子，最方便的是 f-string——在引號前加一個 f，要放變數的地方用大括號 { }：

temp = 25
print(f"目前溫度：{temp}°C")   # 目前溫度：25°C

4. 型別：數字字串 ≠ 數字

"24"（有引號）是字串，24（無引號）是數字。字串不能直接做數學運算，要先用 int() 轉成整數：

s = "24"
print(int(s) + 6)   # 30（先轉成數字再相加）
