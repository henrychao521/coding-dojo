🔁 迴圈

同一件事重複做很多次——累加感測器讀值、數零件、產生燈號圖樣——靠的就是迴圈。也要學會避免最常見的陷阱：無窮迴圈。

🔁 for + range
🔄 while 迴圈
➕ 累加器 total += x
🔍 計數 / 找極值
🪜 巢狀迴圈
⚠️ 避免無窮迴圈

1. for 迴圈：跑固定次數

range(1, n+1) 會產生 1、2、…、n。配合累加器把它們加起來：

total = 0
for i in range(1, 6):   # i = 1,2,3,4,5
    total += i          # 每圈把 i 加進 total
print(total)            # 15

2. while 迴圈：條件成立就一直做

不知道要跑幾次、只知道「結束條件」時用 while。馬達每秒加速 10 rpm 直到達標：

speed = 0
seconds = 0
while speed < 100:   # 還沒到 100 就繼續
    speed += 10
    seconds += 1
print(seconds)         # 10 秒
⚠️ 無窮迴圈陷阱：while 裡如果變數沒有往「結束條件」靠近，迴圈就永遠停不下來。例如忘了寫 speed += 10，speed 永遠是 0、永遠 < 100。在本平台若不小心寫成無窮迴圈，評測會在數秒後自動中止並提醒你。

3. 巢狀迴圈：迴圈裡的迴圈

產生階梯狀的輸送帶燈號：第 i 列點亮 i 顆燈。外層迴圈跑「列」，內層迴圈在這一列裡一顆一顆放燈：

for i in range(1, n+1):     # 外層：第 i 列
    line = ""
    for j in range(i):          # 內層：這一列放 i 顆燈
        line += "●"
    print(line)

內層每跑完一整輪，外層才前進一列。（Python 也能用字串乘法 "●" * i 一次做出一列，結果相同；練習時兩種寫法都可以。）
