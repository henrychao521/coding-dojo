🔀 條件判斷

讓程式「看情況做事」：溫度過高就警示、距離太近就停車。靠的就是 if 條件判斷。

🔀 if / elif / else
⚖️ 比較 > < == >= <=
🔗 邏輯 and / or / not
📏 範圍判斷
🎯 邊界值處理

1. if：條件成立才做

判斷一個條件，成立（True）就執行縮排的那段。注意冒號 : 和縮排：

temp = 75
if temp > 60:
    print("過熱警示！")   # 只有 temp 大於 60 才會印

2. if / elif / else：多選一

多個情況時，由上往下檢查，命中一個就結束。馬達轉速分級：

if rpm < 100:
    level = "低"
elif rpm < 300:      # 100~299
    level = "中"
else:                  # 300 以上
    level = "高"

⚠️ 邊界很容易錯：rpm < 100 時 100 本身算「中」。寫條件時先想清楚邊界值落在哪一段。

3. 範圍判斷：連續比較

判斷讀值是否落在安全範圍，Python 可以直接連續寫：

if low <= value <= high:   # value 在 low 和 high 之間（含兩端）
    print("安全")
